# متجر تبرعات جمعية بُناة التربوية والتعليمية

متجر إلكتروني مستقل لفرص التبرع. كل «منتج» فيه فرصة تبرع (مشروع، برنامج، بند تشغيل، المقر الوقفي)، ومعه تعريف كامل بالجمعية في الصفحة الرئيسية وداخل صفحة كل فرصة. يشمل المتجر لوحة تحكم لإدارته.

## ما يحتويه

**واجهة المتبرع**
- **الصفحة الرئيسية:** واجهة تعريفية، وأرقام الأثر، وفرص التبرع مع تصفية حسب المجال، ومن نحن (الرؤية والرسالة والقيم)، ومنهجية قياس الأثر، والشركاء، والتواصل والحساب البنكي.
- **صفحة الفرصة:**
  - معرض صور، والفئة المستفيدة، والمدة والتكلفة، والوصف، والأثر المتوقع.
  - شريط تقدّم يعرض ما جُمع والمتبقي وعدد المتبرعين.
  - مبالغ مقترحة ومبلغ مخصص، وزر «أكمل المتبقي».
  - مشاركة الفرصة عبر واتساب وX.
  - قسم «تعرّف على الجمعية».
- **سلة التبرعات:** يمكن التبرع لأكثر من فرصة في عملية واحدة، مع خيار «فاعل خير» وخيار الإهداء.
- **الدفع:** إلكتروني عبر ميسّر (مدى وفيزا وماستركارد وApple Pay)، أو تحويل بنكي برقم طلب.

**لوحة التحكم** (`/admin`)
- نظرة عامة: إجمالي التبرعات، وآخر 30 يومًا، والتحويلات المنتظرة، ورسم بياني لآخر 14 يومًا، وتقدّم الفرص.
- فرص التبرع: إضافة وتعديل ورفع صور، والمبلغ المستهدف، والمدعوم مسبقًا، والمبالغ المقترحة، والحالة (منشورة، مسودة، مكتملة، مخفية)، والترتيب، والتمييز.
- التبرعات: بحث وتصفية، واعتماد التحويلات البنكية يدويًا، وإلغاء، وتصدير CSV يُفتح في Excel.
- الشركاء: إضافة شعار وحذفه وترتيبه.
- الإعدادات: النبذة، والرؤية، والرسالة، والقيم، وأرقام الأثر، وصورة الواجهة، والشعار، والتواصل، والحساب البنكي، والمجالات، وتغيير كلمة المرور.

## التشغيل

يتطلب Node.js 18 أو أحدث.

```bash
npm install --omit=dev
cp .env.example .env      # ثم عدّل القيم
npm start
```

بعد التشغيل افتح `/admin/setup` لإنشاء حساب المدير. تظهر هذه الصفحة مرة واحدة فقط، وتطلب `SETUP_TOKEN` إن ضُبط في الملف.

البيانات محفوظة في `data/db.json`، والصور المرفوعة في `public/uploads/`. انسخ المجلدين احتياطيًا بشكل دوري.

## تفعيل الدفع الإلكتروني (ميسّر)

1. افتح حسابًا في ميسّر (moyasar.com)، وخذ المفتاحين من لوحة ميسّر: المفتاح المنشور (Publishable) والمفتاح السري (Secret).
2. في ملف `.env`:
   ```
   PAYMENT_PROVIDER=moyasar
   MOYASAR_PUBLISHABLE_KEY=pk_live_...
   MOYASAR_SECRET_KEY=sk_live_...
   BASE_URL=https://نطاقكم
   ```
3. لـ Apple Pay: سجّل النطاق في لوحة ميسّر، وضع ملف التحقق الذي تعطيك إياه في `public/.well-known/`.
4. اختياري: أضف Webhook في لوحة ميسّر إلى `https://نطاقكم/payment/webhook`، وضع سرّه في `MOYASAR_WEBHOOK_SECRET`.

جرّب أولًا بمفاتيح `pk_test`/`sk_test` وبطاقات ميسّر التجريبية، ثم انتقل إلى مفاتيح `live`.

لا يُعتمد التبرع الإلكتروني إلا بعد أن يتحقق الخادم من الدفع لدى ميسّر مباشرة: الحالة والمبلغ والعملة ورقم الطلب. لا تصل بيانات البطاقة إلى خادم الجمعية.

إن استخدمتم بوابة أخرى (HyperPay أو Tap أو PayTabs)، يمكن إضافتها في `lib/payments.js` بنفس الواجهة.

## النشر على Vercel (الطريقة المعتمدة)

1. ارفع المشروع إلى مستودع GitHub، ثم استورده في Vercel من **Add New → Project**. اختر Framework Preset: **Other**، ولا تغيّر أوامر البناء.
2. من تبويب **Storage** في المشروع أضف **Neon (Postgres)** و**Blob** واربطهما بالمشروع. يضيف Vercel تلقائيًا `DATABASE_URL` و`BLOB_READ_WRITE_TOKEN`. تُنشأ الجداول وتُعبّأ الفرص والشركاء تلقائيًا مع أول زيارة.
3. من **Settings → Environment Variables** أضف:
   - `SESSION_SECRET`: مفتاح عشوائي طويل.
   - `SETUP_TOKEN`: رمز تختاره لحماية صفحة إنشاء المدير.
   - `BASE_URL`: مثل `https://store.bunah.org`.
   - مفاتيح الدفع عند توفرها.

   بعدها أعد النشر (Redeploy).
4. من **Settings → Domains** أضف `store.bunah.org`. إن كان نطاق bunah.org مُدارًا في Vercel فسيُربط تلقائيًا. وإلا فأضف سجل `CNAME` باسم `store` يشير إلى `cname.vercel-dns.com` في مزوّد النطاق.
5. افتح `https://store.bunah.org/admin/setup` لإنشاء حساب المدير.

## النشر على خادم خاص (بديل)

- **خادم VPS:** شغّله بـ `pm2 start server.js --name bunah-store`، وضع أمامه Nginx مع شهادة SSL من Let's Encrypt.
- **Docker:** `docker build -t bunah-store . && docker run -d -p 3000:3000 --env-file .env -v bunah-data:/app/data -v bunah-uploads:/app/public/uploads bunah-store`
- يجب أن يعمل الموقع على HTTPS، وهذا شرط لبوابة الدفع وApple Pay.

## الأمان

- كلمات المرور مشفرة بـ scrypt.
- جلسات الدخول بكوكيز موقّعة وHttpOnly.
- حماية CSRF لكل نماذج اللوحة.
- تحديد محاولات الدخول إلى 8 محاولات كل 15 دقيقة.
- سياسة أمان محتوى (CSP).
- تحقق من نوع الصور المرفوعة وحجمها (4MB).
